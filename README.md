🛒 Retail Sales Intelligence Platform
📌 Project Overview

The Retail Sales Intelligence Platform is a SQL-based data analytics project built using MySQL to analyze retail sales data and solve real-world business problems.

The project focuses on designing a relational database, loading structured retail data, and extracting meaningful business insights using advanced SQL techniques such as Joins, Window Functions, Common Table Expressions (CTEs), Aggregations, Subqueries, and Conditional Logic.

The objective is to demonstrate practical SQL and data analysis skills that can be applied to real-world retail business scenarios.

🎯 Business Objective

The main objective of this project is to answer important retail business questions and transform raw transactional data into actionable insights.

Some key areas of analysis include:

Customer purchasing behavior

Order and transaction analysis

Top-performing products

Identifying high-value customers

🧠 Advanced SQL Analysis
🔹 Common Table Expressions (CTEs)

CTEs are used to break complex queries into smaller and more readable steps.

Example:

WITH customer_sales AS (
    SELECT
        customer_id,
        SUM(order_amount) AS total_sales
    FROM Orders
    GROUP BY customer_id
)
SELECT *
FROM customer_sales
ORDER BY total_sales DESC;
🔹 Window Functions

Window functions are used for ranking, comparisons, and calculating values across related rows without collapsing the result set.

Example:

SELECT
    customer_id,
    total_sales,
    RANK() OVER (
        ORDER BY total_sales DESC
    ) AS sales_rank
FROM customer_sales;

Other window functions explored in the project include:

ROW_NUMBER()
RANK()
DENSE_RANK()
LAG()
LEAD()
SUM() OVER()
AVG() OVER()
🔹 Joins

Joins are used to combine information from multiple tables.

SELECT
    c.customer_name,
    o.order_id,
    p.product_name,
    oi.quantity
FROM Customers c
JOIN Orders o
    ON c.customer_id = o.customer_id
JOIN Order_Items oi
    ON o.order_id = oi.order_id
JOIN Products p
    ON oi.product_id = p.product_id;
